# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for security concerns.

Instead, use GitHub's [Private Vulnerability Reporting](https://github.com/Danielbluz/teamdesk-skill/security/advisories/new) to submit your report confidentially.

We will acknowledge your report within 7 days and work with you to address the issue.

## Scope

This repository contains a Claude Code skill (prompt templates and API reference documentation) for TeamDesk. It does **not** contain:

- Authentication credentials or API tokens
- Executable server-side code
- User data

Security reports related to the TeamDesk platform itself should be directed to [TeamDesk support](https://www.teamdesk.net).
